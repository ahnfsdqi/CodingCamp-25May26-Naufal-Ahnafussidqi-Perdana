# FinanceFlow - Expense & Budget Visualizer
**Submission: SEFC Coding Camp - Batch 25 May 2026**

FinanceFlow adalah aplikasi manajemen keuangan berbasis web yang dirancang dengan estetika **Neo-Brutalism**. Aplikasi ini membantu pengguna melacak pengeluaran harian secara instan melalui visualisasi data yang responsif.

## 🚀 Fitur Utama (MVP)
- **Real-time Balance**: Kalkulasi saldo otomatis setiap ada perubahan data.
- **Transaction Tracker**: Input pengeluaran dengan kategori (Food, Transp, Entertain).
- **Visual Analytics**: Diagram lingkaran interaktif menggunakan Chart.js untuk distribusi kategori.
- **Local Persistence**: Data tersimpan aman di browser melalui LocalStorage API.

## ⚡ Tantangan Opsional (Implemented)
1. **Dark/Light Mode**: Perpindahan tema instan untuk kenyamanan visual.
2. **Advanced Sorting**: Mengurutkan transaksi berdasarkan jumlah atau kategori.
3. **Budget Highlight**: Peringatan visual otomatis jika pengeluaran melebihi batas.

## 🛠️ Tech Stack
- **Structure**: Vanilla HTML5
- **Styling**: Pure CSS3 (Neo-Brutalism Style)
- **Logic**: Vanilla JavaScript (No Frameworks)
- **Library**: Chart.js (via CDN)

## 📁 Struktur Folder
- `css/style.css` (Single CSS file)
- `js/app.js` (Single JS file)
- `.kiro/` (Project tracking folder)
